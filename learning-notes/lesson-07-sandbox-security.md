## 🧠 核心心智模型

本课要建立的心智模型是：

```text
用户需求
  ↓
Codex Harness 组织流程
  ↓
LLM / 工具 / 上下文 / 状态 互相配合
  ↓
产生可控、可解释、可恢复的 Agent 行为
```

对于 `沙箱与安全 —— “安全护栏”`，请优先记住三件事：

1. **它解决什么问题**：为什么工业级 Agent 离不开这一层。
2. **它和主循环的关系**：它是在 LLM 调用前、工具执行中，还是结果返回后发挥作用。
3. **它的失败后果**：如果这一层设计不好，Agent 会出现什么问题。
